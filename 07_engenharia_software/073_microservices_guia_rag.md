# Assunto 073 — Microservices

## Metadados
- disciplina: Engenharia de Software / Arquitetura
- assunto_id: 073
- prioridade_rag: alta

## Escopo
- serviços pequenos e independentes em nível conceitual;
- bounded context quando a fonte utilizar DDD;
- comunicação síncrona e assíncrona;
- API gateway;
- descoberta de serviços;
- tolerância a falhas;
- observabilidade;
- dados distribuídos e consistência;
- implantação independente.

## Questões
Comparar arquitetura monolítica e microsserviços sem afirmar que microsserviços são sempre superiores. Explorar trade-offs, acoplamento, comunicação e consistência distribuída.
