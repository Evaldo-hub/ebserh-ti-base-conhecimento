# Assunto 044 — REST / RESTful

## Metadados
- disciplina: Arquitetura e Integração

## Escopo
- recursos e representações;
- interface uniforme;
- stateless;
- cache;
- sistema em camadas;
- métodos HTTP e semântica;
- códigos de status;
- idempotência e segurança de métodos;
- REST versus RPC/SOAP.

## Questões
Não definir REST apenas como API HTTP com JSON. Separar restrições arquiteturais REST de convenções comuns de APIs web. Para métodos HTTP e status codes, usar referências HTTP/IETF atuais.
